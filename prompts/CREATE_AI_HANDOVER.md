AI_HANDOVER.md 作成依頼

Project ChaseのAI開発環境に、AI・チャットルーム・担当AIが変わった際に、現在の作業状況を正確に引き継ぐための "AI_HANDOVER.md" を追加してください。

目的

このファイルは、Project Chaseのプロジェクト全体を説明するためのものではありません。

「今この瞬間、どこまで作業が進んでいて、次のAIが何をすればいいのか」を引き継ぐための専用ファイルです。

ChatGPT、Claude、Geminiなど、担当AIやチャットルームが変更されても、次のAIがこのファイルを読むことで、直前の作業状態から安全に続きを再開できることを目的とします。

---

まず必ず確認すること

ファイルを作成する前に、現在のProject Chaseに存在する以下のドキュメントを確認してください。

- "AI_GUIDE.md"
- "AI_PROJECT_MANAGER.md"
- "CURRENT_STATUS.md"
- "SPECIFICATION.md"
- "DECISIONS.md"
- "CHANGELOG.md"
- "DEVLOG.md"
- "TASKS.md"
- "ROADMAP.md"

その他、Project Chaseに関連するドキュメントが存在する場合は、それらも必要に応じて確認してください。

既存ドキュメントと役割が重複しないようにしてください。

---

AI_HANDOVER.md の役割

以下の情報だけを中心に記録してください。

1. 最終更新日時

- 最終更新日時
- 最後に作業したAI
- 必要であれば作業した環境

2. 現在の作業

- 現在取り組んでいるタスク
- どこまで完了しているか
- 現在どの段階にあるか

3. 直前に行った変更

- 直前のAIが何を変更したのか
- 変更したファイル
- 変更内容
- 動作確認の結果

4. 現在の状態

以下を明確にしてください。

- 正常に動作している部分
- 未確認の部分
- 問題が発生している部分
- エラーがある場合はエラー内容
- 現在わかっていないこと

5. 最後に正常だった状態

特に重要です。

**「どの状態までは正常だったのか」**を可能な限り具体的に記録してください。

これにより、問題が発生した場合に復旧地点を判断できるようにします。

6. 次にやること

次のAIが最初に何をすべきなのかを、優先順位付きで記録してください。

例：

1. 現在のコードを確認
2. エラー原因を調査
3. 修正案を提示
4. ユーザーの承認を待つ
5. 修正
6. 動作確認

7. 注意事項

次のAIが作業するときに注意すべきことを記録してください。

特に、

- 大幅なコード変更を避ける
- 既存仕様を勝手に変更しない
- 不明点を推測で実装しない
- 複数ファイルを変更する場合は変更理由を明確にする
- 現在の状態を壊す可能性がある変更は事前に確認する

など、引き継ぎ時の事故を防ぐ内容を含めてください。

---

重要なルール

"AI_HANDOVER.md" は、プロジェクト全体の正式な仕様書ではありません。

したがって、

- ゲーム仕様 → "SPECIFICATION.md"
- プロジェクト全体の状態 → "CURRENT_STATUS.md"
- 決定事項 → "DECISIONS.md"
- 作業履歴 → "DEVLOG.md"
- 変更履歴 → "CHANGELOG.md"
- タスク → "TASKS.md"
- 長期計画 → "ROADMAP.md"

を優先してください。

"AI_HANDOVER.md" では、それらを重複して詳しく記載するのではなく、

「次のAIが今の作業を再開するために必要な情報」

に絞ってください。

---

AI切り替え時の運用も定義してください

"AI_HANDOVER.md" の末尾に、

「AI引き継ぎ手順」

というセクションを作成してください。

そこには、

1. 現在のAIが作業を終了する
2. "AI_HANDOVER.md" を最新状態に更新する
3. 必要に応じて "CURRENT_STATUS.md"、"TASKS.md"、"DEVLOG.md" 等も更新する
4. コード変更前のバックアップを確認する
5. 次のAIにプロジェクトと "AI_HANDOVER.md" を渡す
6. 次のAIはまずドキュメントを確認する
7. 現在の状態を理解してから作業を開始する

という流れを整理してください。

---

作成時の注意

現在のProject Chaseの実際の状況を確認したうえで作成してください。

存在しない情報を推測して記載しないでください。

不明な情報は、

"未確認"

または

"情報なし"

と明記してください。

また、既存のProject Chaseの方針や仕様を勝手に変更しないでください。

今回は**"AI_HANDOVER.md" の作成だけを行ってください。**

既存のコードや他のドキュメントを変更しないでください。

作成後、

1. "AI_HANDOVER.md" の内容
2. このファイルが既存ドキュメントとどのように役割分担するのか
3. 今後AIを切り替える際の具体的な使い方

を簡潔に説明してください。
